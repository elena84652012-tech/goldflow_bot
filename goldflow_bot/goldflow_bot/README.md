# 💰 GoldFlow

**Telegram-бот для личного учёта финансов** с золото-зелёной темой, интуитивным вводом на естественном языке и красивыми графиками прямо в чате.

## ✨ Возможности

- 💬 **Ввод без команд** — просто пиши `500 продукты` или `+5000 зарплата`, бот сам поймёт сумму, категорию и тип операции
- 📊 **Отчёты** — круговая диаграмма расходов по категориям за 30 дней
- 📈 **Динамика баланса** — линейный график изменения баланса по дням
- 🎯 **Бюджеты** — устанавливай лимиты по категориям и следи за прогрессом (с эмодзи-барами 🟩🟩🟩⬜⬜)
- 🖱️ **Инлайн-кнопки** — никаких сложных команд, всё через понятное меню

## 🎨 Дизайн

Все графики оформлены в фирменной золото-зелёной палитре на тёмном фоне — выглядит как настоящий финансовый продукт, а не просто скрипт.

## 🚀 Быстрый старт

### 1. Клонируй репозиторий

```bash
git clone https://github.com/твой_username/goldflow-bot.git
cd goldflow-bot
```

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Настрой токен бота

Создай своего бота через [@BotFather](https://t.me/BotFather) в Telegram, получи токен, затем:

```bash
cp .env.example .env
```

И впиши токен в `.env`:

```
BOT_TOKEN=твой_токен_сюда
```

### 4. Запусти бота

```bash
python bot.py
```

Готово — бот работает, пиши ему в Telegram!

## 📁 Структура проекта

```
goldflow-bot/
├── bot.py            # точка входа, обработчики команд и кнопок
├── database.py        # работа с SQLite (операции, бюджеты)
├── charts.py           # генерация графиков (matplotlib)
├── categorizer.py      # распознавание суммы/категории из текста
├── config.py            # загрузка токена из .env
├── requirements.txt
├── .env.example
└── .gitignore
```

## 🌐 Деплой (чтобы бот работал 24/7)

Проект готов к деплою на [Render](https://render.com) или [Railway](https://railway.app):

1. Залей код на GitHub (см. `.gitignore` — токен туда не попадёт)
2. Подключи репозиторий к Render/Railway
3. Добавь переменную окружения `BOT_TOKEN` в настройках сервиса
4. Укажи команду запуска: `python bot.py`

## 🛠️ Технологии

- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) — асинхронная работа с Telegram Bot API
- [matplotlib](https://matplotlib.org/) — генерация графиков
- SQLite — хранение данных без внешней базы

| `/budget` | Управление лимитами бюджета |
